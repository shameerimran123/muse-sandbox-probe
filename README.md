# Muse Sandbox Probe

A limited environment-inspection probe for GitHub Actions hosted runners. What runs here: small human-reviewed checks of runner configuration, filesystem access, network reachability, resource-limit visibility, and job timeout behavior. No AI-generated code, no product code, and no real bugs. This probe does not execute untrusted code or certify that GitHub Actions can safely contain it. Results describe only the observed runner and this probe configuration.
